
## Tags, thumbnails and the catalog browser (2026-09-06)

- **Tags** (`src/game/catalogTags.ts`): zone vocabulary farm/kitchen/dining/outdoor, kind vocabulary food/ingredient/cooking/prep/tableware/appliance/storage/seating/furniture/plant/tool/fence/decor/structure, size class derived from the index size (hand-held < 30 cm, tabletop < 70 cm, floor < 2 m, large). `suggestTags(id, name, folder)` is keyword heuristics (matches against a spaced copy of the id so snake_case words get word boundaries; multi-word keys use "[_ ]"). All 346 models were tagged once with it; corrections belong in the lab (a tag editor in the rename panel is the next step).
- **Thumbnails**: the lab renders 256² transparent PNGs (`captureThumbnail` in `src/model-lab.ts`: hides the ground, frames the bounding sphere for a square, `Tools.CreateScreenshotUsingRenderTargetAsync`) and posts them to `/__lab/save-thumbnail`; stored in `src/assets/catalog/thumbs/<id>.png` (3 MB for 345), `thumb: true` in the index. Auto after an import and after a save; the 📸 button renders missing ones (Shift = all); dev hook `window.__labThumbs.generate(ids?)`. ~0.9 s per model — a full run is ~5 min and aborts if the page reloads (any edit of a module the lab imports).
- **Catalog browser** (`src/catalogBrowser.ts` + `.css`): tiles + search + zone/kind chips + size/sort selects + ★ favourites + 📁 folder rail + tile size; recents strip; grid keyboard navigation (arrows, Home/End, Enter); state per host in localStorage (`<storageKey>:browser`). Options: `idAttribute` (host's data attribute on tiles), `extras` (non-catalog tiles), `hidden`, `onOpen/onContext/onDragStart/onRendered`. The lab (`#lab-browser`, storageKey farm-lab) replaced its folder list with it: right-click menu (open, rename/move, duplicate, merge into the open object, re-render thumbnail, remove), drag tile→tile merges, tile→folder-rail moves, body-focus arrows step the grid. Decorate mode mounts it once per session into `.decorate-library` (storageKey farm-decorate, `idAttribute: "data-model"` so the existing pointer hold/drag code works; tiles get `draggable=false` because native drag would swallow the pointer gesture); `render()` only re-attaches the host and re-marks the held tile.
